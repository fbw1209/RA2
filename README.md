## 🛠️ 安装步骤

1. **解压安装包**  
   将下载的`.zip`文件解压到 **纯英文路径**（例如 `D:\RA2`）。  
   ⚠️ 路径中不要出现中文或空格，否则游戏可能无法启动。

2. **设置兼容性**（核心一步）  
   - 进入游戏目录，找到 `Ra2.exe`（如果是尤里的复仇则为 `Yuri.exe`）  
   - 右键 → **属性** → **兼容性** 选项卡  
   - ✅ 勾选 “以兼容模式运行这个程序” → 选择 **Windows XP (Service Pack 3)**  
   - ✅ 勾选 “以管理员身份运行此程序”  
   - 点击 **确定** 保存

3. **开始游戏**  
   双击 `Ra2.exe`，即可进入游戏。如果画面显示异常或黑屏有声音，请联系作者
